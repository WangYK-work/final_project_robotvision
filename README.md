# Smart AirBoard 使用指南

基于摄像头双手交互的网页画板，支持局部绘画、全图预览、固定选色及自动肖像绘制。

## 启动

使用原来的 `virtual-painter` 环境，在项目目录运行：

```bash
conda activate virtual-painter
python app.py
```

浏览器打开终端给出的地址，默认 `http://127.0.0.1:7860`。若提示 7860 端口被占用，先关闭旧的运行实例；需要时可在 `app.py` 修改端口。

新环境可使用项目中的 `environment.yml`，或在 Python 3.9 环境安装 `requirements.txt`。本次更新未增加依赖；人像功能使用已有 MediaPipe 和 OpenCV 随附模型，无需密钥或额外下载模型。摄像头由运行 Python 的电脑读取。

## 界面

- 左上：摄像头画面。
- 画板下方：紧凑的中英文工具按钮和手势确认进度。
- 左下：局部画板；6 号模式下临时显示两行四列固定色板。
- 右侧：占据主要空间的完整大画板，分辨率 1280×960。
- 完整画板上的半透明黑框标示局部区域，不写入作品。

## 基本操作

左手掌心大致朝向镜头，用数字手势选工具。普通工具保持约 **0.5 秒**，清屏保持 **1.2 秒**；保持同一手势不会重复触发。要再次使用相同手势，先放下或松开约 0.25 秒。识别不明确时保持当前工具；按钮也可鼠标点击。

| 数字与工具 | 左手手势 | 右手操作 |
| --- | --- | --- |
| 1 画笔 / Pen | 只伸食指 | 先移动定位，拇指食指捏合落笔，松开结束 |
| 2 橡皮 / Eraser | 食指、中指伸出 | 捏合擦除，恢复白底 |
| 3 清空画板 / Clear | 食指、中指、无名指伸出 | 保持左手手势 1.2 秒，清空整张大画板 |
| 4/5 视图 / View | 除拇指外四指伸出，或五指张开 | 拇指＋食指捏合移动；拇指＋中指捏合上拖放大、下拖缩小，范围 1–8 倍 |
| 6 选择颜色 / Colors | 拇指、小指伸出 | 指向大色块并捏合确认，也可鼠标点击 |
| 7 肖像 / Portrait | 拇指、食指、中指指尖聚拢，另外两指收起 | 胜利手势保持约 0.6 秒触发拍摄 |

切换工具后，请先松开右手，再捏合绘画或操作，避免误留笔迹。4、5 均进入同一个视图工具：拇指＋食指捏合拖动画面；拇指＋中指捏合上下拖动缩放。切换操作前需松开两种捏合；同时捏住食指和中指时暂停，避免误操作。右手离开画面后重新捏合会以当前位置和倍率为起点。页面也保留缩放滑块。

6 号提供黑、红、橙、黄、绿、蓝、紫、棕八种固定颜色。选色期间不会绘画，色板不写入作品；选中后自动回到画笔，松开右手后才能再次落笔。页面显示当前颜色。原吸管由固定色板替代；页面下方保留自由色盘和 HSB 精确调色滑块，可选择任意颜色。

在页面下方可切换原始、固定平滑和自适应平滑轨迹，并开关圆形、矩形和三角形规整。已识别的闭合图形会自动结束；松开后可画下一笔。

## 自动肖像

在页面下方可用鼠标选择“肖像风格”：

- **黑金手绘（默认）**：恢复最初锐利的黑金分层色块和轮廓，保留大块深黑色阴影；只去掉人为生成的规则排线与点阵。
- **灰度**：去背景大头的灰度照片效果，不添加黑金色调。

黑金、灰度只绘制大头；梵高、毕加索对完整摄像头画面做风格迁移，包含人物、肩膀和背景，不要求人脸检测成功。选择在下一次拍摄时生效；正在绘制时切换不会改变当前肖像。


1. 保证光线充足，头部完整入镜，正对摄像头，尽量使用与头发有对比的背景。
2. 选择 `7 Portrait`。
3. 右手伸出食指和中指并分开，收起无名指和小指，保持胜利手势约 0.6 秒。
4. 拍摄成功后，自动提取头部和头发、去掉背景及肩膀，按下方“肖像风格”选项生成黑金手绘或灰度效果。
5. 肖像在整张大画板上居中放大，由红色十字光标逐步绘制，约 24 秒完成；状态栏显示进度。

肖像位置与局部视图无关，按比例尽量占满大画板高度或宽度，不拉伸头部。局部窗口只显示它对应的那一部分。背景透明区域保留旧画，头部覆盖处会更新为肖像。

绘制期间可以放下双手。点击“取消肖像绘制”或切换工具，会取消未完成的绘制并恢复原内容；已完成的肖像不会被取消按钮撤销。重新拍摄前先放下胜利手势，再次举起。

## 常见问题

- **数字手势未识别**：保持手掌大致朝向镜头，让整只左手入镜；先看确认进度，必要时使用网页按钮。3 需要伸出三指，7 是三指尖聚拢。4 收起拇指，5 张开拇指。
- **缩放略有抖动**：用拇指与中指捏合后缓慢上下拖动，松开停止；也可以使用页面缩放滑块。

- **未检测到人脸/头部**：正面靠近镜头、改善照明、减少遮挡，放下胜利手势再重试。
- **发型边缘不完整**：这是自动分割和头部范围估计的限制；换对比明显的背景，避免头发超出画面。较长、蓬松的发型可能被截掉一部分。
- **画面效果与官网手绘不完全一样**：这是本地算法实现的分层黑金色块与轮廓效果，不是人工绘画，也不调用生成式绘图服务。
- **绘制超过 24 秒**：低帧率时会延长，以保持逐步绘制过程。
- **前面出现 MediaPipe 警告**：若网页和摄像头正常工作，先看是否存在最终的异常堆栈；普通初始化日志不代表启动失败。

## 7 号神经肖像

在“肖像风格”选择“梵高 · 全画面”或“毕加索 · 全画面”，调整下方强度（默认 0.3），再进入 7 号，用右手胜利手势拍照。状态栏先显示后台生成进度，再显示逐步绘制进度。生成阶段和绘制阶段都可以取消；切换工具也会取消，未完成的绘制恢复原画布。色盘、HSB、黑金和灰度保持原用法。

神经画风使用未经手部骨架标注的完整快照，不抠图；结果等比例铺入完整画板，比例不同时留边，覆盖范围内的原画被替换，取消未完成绘制会恢复。神经处理默认为长边 256 像素、200 步；画风和强度在拍摄时固定，途中修改只影响下一张。脸部仍可能出现纹理失真；毕加索参考主要迁移颜色与纹理，不保证五官重排。

主程序仍使用 virtual-painter。后台自动查找同级 ai-learning 环境；如果不同，启动前设置 `AIRBOARD_NEURAL_PYTHON` 为装有 PyTorch 的 Python 可执行文件绝对路径。依赖与下载方法见 [神经样例指南](experiments/neural_style/README.md)。缺模型时会在状态栏提示，运行时不自动联网下载。临时照片只存本机，成功、失败或取消后清理；生成超时上限 5 分钟。
